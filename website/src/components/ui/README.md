# ui

Small, generic, reusable building blocks with no page/route knowledge of
their own (buttons, spinners, status banners, form fields). If a component
could plausibly be reused on an unrelated page, it belongs here.

Nothing has been moved here yet -- the existing `FullPageSpinner.tsx` and
`StatusViews.tsx` in the parent `components/` folder are exactly this kind
of component; move them in here next time either one needs a real edit,
rather than as a separate churn-only PR.
